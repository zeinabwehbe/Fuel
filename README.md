# Fuel

A virtual coffee shop storefront built with React. Browse drinks and pastries, view product details and manage a shopping cart.

## Features

- Home page with popular and new items
- Drink and pastry category pages
- Product detail pages
- Shopping cart with shared state through React Context
- Login and sign-up page

## Tech stack

React, React Router, Create React App, CSS

## Getting started

```bash
npm install
npm start
```

Then open http://localhost:3000.
